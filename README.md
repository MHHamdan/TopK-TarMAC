# agentic-marl

Autonomous research repo targeting a workshop-paper draft on the agentic RL / MARL
track. Contribution scope: cooperative MARL, attention-based agent communication,
scalable training for large agent populations, agentic RL for LLM agents, or
distributed rollout efficiency.

## Status

See [STATUS.md](STATUS.md) for the active phase and next action.
See [RESEARCH_LOG.md](RESEARCH_LOG.md) for the chronological log.
See [DECISIONS.md](DECISIONS.md) for non-obvious choices and rationale.

## Quick start

```bash
uv venv .venv --python 3.11
source .venv/bin/activate
uv pip install -e .[dev]
pytest -q tests/test_smoke.py
```

## Layout

| Path | Purpose |
|------|---------|
| `configs/` | YAML configs per experiment |
| `src/envs/` | MARL env wrappers |
| `src/agents/` | Baseline + proposed methods |
| `src/training/` | Train loops, distributed glue |
| `src/eval/` | Evaluation harnesses |
| `src/utils/` | Logging, seeding, plotting |
| `scripts/` | `train.py`, `eval.py`, `plot.py`, `make_figures.py`, `make_tables.py`, `reproduce.sh` |
| `results/` | Raw logs, checkpoints, metrics CSVs |
| `literature/` | `notes/`, `references.bib`, `literature_review.md` |
| `paper/` | LaTeX source + figures/tables generated by scripts |
| `proposals/` | Phase 3 contribution candidates |
| `tests/` | Smoke + unit tests |

## Reproducibility

Every paper number traces to:
- a git SHA (recorded in `results/MASTER_LOG.csv`),
- a YAML config in `configs/`,
- a seed in the config or CLI,
- and a row in `results/MASTER_LOG.csv` with timestamp, wall time, GPU-hours.

`bash scripts/reproduce.sh` regenerates every figure/table the paper cites.
