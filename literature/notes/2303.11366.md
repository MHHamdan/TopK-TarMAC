# Reflexion: Language Agents with Verbal Reinforcement Learning

**Key:** `shinn2023reflexion` — arXiv:2303.11366 (2023, NeurIPS).

**Authors:** Noah Shinn and Federico Cassano and Edward Berman and Ashwin Gopinath and Karthik Narasimhan and Shunyu Yao

## Abstract (verbatim or condensed from arXiv)

Replaces gradient updates with linguistic self-reflection: after each failed trial, the agent writes a self-critique that is appended to context for the next trial, achieving multi-trial improvement without weight updates.

## Method (5 lines)

Actor LLM → environment trajectory → evaluator computes scalar reward → self-reflection generator writes natural-language critique → memory buffer; repeated for k trials.

## Benchmarks + headline numbers

ALFWorld, HotpotQA, HumanEval/MBPP; large gains over ReAct baselines.

## Limitations / open problems flagged by authors

Relies on the LLM's introspective capacity; weak on novel tool surfaces.

## Connection to MARL-IoTP / target team

Sample-efficient inference-time RL alternative; orthogonal to gradient methods.
