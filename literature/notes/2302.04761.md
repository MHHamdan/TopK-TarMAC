# Toolformer: Language Models Can Teach Themselves to Use Tools

**Key:** `schick2023toolformer` — arXiv:2302.04761 (2023, NeurIPS).

**Authors:** Timo Schick and Jane Dwivedi-Yu and Roberto Dessì and Roberta Raileanu and Maria Lomeli and Luke Zettlemoyer and Nicola Cancedda and Thomas Scialom

## Abstract (verbatim or condensed from arXiv)

Self-supervised tool-use: the model proposes API calls inside generated text, executes them, and keeps the call only if the answer improves the downstream language-modelling loss.

## Method (5 lines)

Sample API-call insertions; filter by perplexity gain; fine-tune on retained calls.

## Benchmarks + headline numbers

Calculator, QA, search, translation tools; improves zero-shot QA.

## Limitations / open problems flagged by authors

Filtering proxy is brittle; no multi-step tool composition.

## Connection to MARL-IoTP / target team

Earliest large-scale self-supervised tool-RL signal.
